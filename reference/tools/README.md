# reason
the reason i create this patcher is because as a phigros player,

# how it works
the patcher applys a binary patch to unityframeworks so it dont quit if detected a lower ios version
and it moves the whole wramework from old ipa to newone, 
that's the reason you will see the start screen shows 3.19.2, dont worry, the inside is 3.20
